# BELTSENTINEL AI

## Intelligent Conveyor Health Monitoring & Early Damage Detection

BELTSENTINEL AI is a multimodal conveyor monitoring prototype developed for Smart India Hackathon 2026 Problem Statement 26008.

The system combines YOLO-based AI vision, ESP32 sensor telemetry, AI–sensor fusion, risk assessment and J1–J5 joint localization to identify and monitor conveyor belt abnormalities.

## Key Features

- YOLO-based belt damage detection
- Crack, tear, edge damage and joint damage detection
- ESP32-based sensor telemetry
- Vibration monitoring
- Acoustic monitoring
- Temperature and humidity monitoring
- Encoder-based belt/joint localization
- AI–sensor fusion
- Risk assessment
- Normal / Warning / Critical alerts
- Historical analytics
- Maintenance reporting
- J1–J5 joint localization

## Prototype

- 120 cm mini conveyor
- 5 physical joints: J1–J5
- ESP32
- Camera
- DHT11
- SW-420
- LM393
- Rotary encoder
- L298N motor driver
